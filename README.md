# مشروع منصة OLX-Like للخدمات والسلع
## رؤية المشروع
بناء سوق رقمي يركز على الخدمات كأولوية بجانب العقارات والسيارات، مع الالتزام بالبساطة والسرعة.

## هيكلية المشروع (Architecture)
- `/config`: إعدادات الربط وقاعدة البيانات.
- `/actions`: المنطق البرمجي (Backend Logic).
- `/includes`: القوالب المتكررة (Header/Footer).
- `/assets`: ملفات CSS والرسوميات.
- `/uploads`: مخزن صور الإعلانات (صورة واحدة لكل إعلان).
